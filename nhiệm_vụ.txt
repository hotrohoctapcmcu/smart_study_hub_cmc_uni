1. Phân công công việc theo thành viên
1. Văn Tuấn – Trưởng nhóm, điều phối và phát triển AI
- Nghiên cứu, triển khai chức năng lấy dữ liệu học tập từ các nguồn của trường để cung cấp cho AI.
- Xây dựng luồng gửi dữ liệu đầu vào lên AI, xử lý yêu cầu và nhận câu trả lời trả về ứng dụng.
- Phối hợp với Long Nhật tích hợp chức năng AI thành API để Frontend có thể sử dụng.
- Điều phối nhóm kiểm tra, sửa lỗi, tái cấu trúc và cập nhật các chức năng của dự án.
- Hỗ trợ Anh Tuấn thiết kế phương án lấy, chuẩn hóa và kết hợp dữ liệu từ IU và EDUX.
- Theo dõi tiến độ thực hiện các Sprint, phân công công việc và hỗ trợ các thành viên xử lý vấn đề kỹ thuật.
- Định hướng phát triển các tính năng AI cho những Sprint tiếp theo.
2. Long Nhật – Phát triển API và tích hợp hệ thống
- Tích hợp phần AI do Văn Tuấn phát triển thành API để các chức năng trên Frontend có thể gọi và sử dụng.
- Kiểm tra, sửa lỗi các API hiện có, bao gồm:
  - API lấy hồ sơ sinh viên trả về lỗi 404 khi chưa có dữ liệu đồng bộ.
  - API lấy thời khóa biểu, bài tập và lịch thi chưa đồng bộ hoặc xử lý dữ liệu chưa chính xác.
  - API xác thực, đồng bộ dữ liệu và xử lý phiên đăng nhập.
  - API chưa khớp giữa cấu trúc dữ liệu Backend và yêu cầu của Frontend.
  - API xử lý lỗi và phản hồi chưa thống nhất.
- Tích hợp API lấy dữ liệu từ EDUX vào hệ thống.
- Kết nối Backend với SQL Server, kiểm tra cấu hình kết nối và hoạt động truy vấn dữ liệu.
- Phối hợp với Anh Tuấn kiểm tra dữ liệu nhận từ EDUX và với Thắm để bảo đảm dữ liệu được lưu trữ đúng cấu trúc.
- Kiểm thử API, xử lý lỗi phát sinh và hỗ trợ tích hợp các chức năng giữa Backend và Frontend.
3. Anh Tuấn – Phân tích và xử lý dữ liệu EDUX
- Nghiên cứu cấu trúc dữ liệu và các chức năng trên hệ thống EDUX.
- Xây dựng các hàm phục vụ đăng nhập và lấy dữ liệu từ EDUX.
- Phân tích, xử lý và chuẩn hóa dữ liệu EDUX để cung cấp cho Backend.
- Xác định các trường dữ liệu cần thiết cho bài tập, thời hạn nộp bài và các thông tin học tập liên quan.
- Phối hợp với Văn Tuấn lên phương án thiết kế dữ liệu tổng hợp từ hai nguồn IU và EDUX.
- Đề xuất cách ánh xạ, phân biệt và hợp nhất dữ liệu giữa hai hệ thống, hạn chế dữ liệu trùng lặp hoặc sai lệch.
- Hỗ trợ Long Nhật kiểm tra dữ liệu đầu ra của EDUX API và xử lý các vấn đề trong quá trình tích hợp.
4. Hồng Thắm – Thiết kế, quản lý và kiểm tra cơ sở dữ liệu
- Rà soát, điều chỉnh và hoàn thiện thiết kế cơ sở dữ liệu SQL Server theo yêu cầu thực tế của dự án.
- Xác định các bảng, trường dữ liệu, khóa chính, khóa ngoại và quan hệ giữa các bảng.
- Thiết kế cơ chế lưu trữ dữ liệu học tập cá nhân, thời khóa biểu, bài tập, lịch thi và các thông tin liên quan.
- Xây dựng và điều chỉnh câu lệnh SQL tạo bảng, cập nhật cấu trúc, truy vấn và quản lý dữ liệu.
- Kiểm tra tính chính xác, nhất quán và toàn vẹn dữ liệu trong quá trình đồng bộ từ IU và EDUX.
- Phối hợp với Long Nhật cấu hình kết nối SQL Server với Backend và kiểm tra các thao tác thêm, sửa, xóa, truy vấn dữ liệu.
- Hỗ trợ xử lý lỗi liên quan đến cấu trúc bảng, dữ liệu thiếu, dữ liệu trùng lặp và sai kiểu dữ liệu.
- Hoàn thiện tài liệu mô tả cơ sở dữ liệu, phục vụ việc phát triển, kiểm thử và bảo trì hệ thống.
5. Kiều Trang – Phát triển Frontend và giao diện người dùng
- Phát triển, hoàn thiện giao diện và xử lý các chức năng Frontend của ứng dụng.
- Triển khai chức năng đồng hồ Pomodoro hỗ trợ quản lý thời gian học tập và tập trung.
- Phát triển giao diện thời khóa biểu, lịch học và các chức năng hỗ trợ quản lý lịch học.
- Xây dựng giao diện kho tài liệu học tập, hỗ trợ hiển thị, tìm kiếm và quản lý tài liệu.
- Phối hợp với Long Nhật kết nối Frontend với các API tương ứng.
- Kiểm tra dữ liệu hiển thị, trạng thái tải dữ liệu, thông báo lỗi và khả năng tương thích giữa giao diện với Backend.
- Tiếp tục hoàn thiện các chức năng thuộc Sprint 1 còn tồn đọng và triển khai một số chức năng thuộc Sprint 2.
- Thực hiện kiểm thử giao diện, sửa lỗi và cải thiện trải nghiệm người dùng.
- Phối hợp hoàn thiện các chức năng Frontend cho những Sprint tiếp theo.
